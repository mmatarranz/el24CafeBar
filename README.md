# Café Bar El 24 - Landing Page

Landing page moderna, ultra-rápida y optimizada para conversión (CRO), SEO técnico y motores de búsqueda con IA (AIO / LLMO) para **Café Bar El 24** (Leganés, Madrid).

🌐 **Web oficial:** [el24cafebar.es](https://el24cafebar.es)

---

## 🚀 Características Principales

- **Diseño UI/UX Moderno & Responsivo**: Adaptado 100% a móviles, tablets y escritorio.
- **Fondos a Ancho Completo (Full-Width / Parallax)**: Utilización de las fotografías originales del proyecto distribuidas en secciones estratégicas, con imágenes claras y nítidas.
- **Optimización de Conversión (CRO)**:
  - Botones directos a llamada telefónica (`tel:917087385`).
  - Enlaces directos a la Carta Digital oficial.
  - Barra de acción rápida sticky inferior para dispositivos móviles.
- **SEO Técnico & Estructuración LLMO / AIO**:
  - Marcado semántico HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`).
  - Jerarquía estricta de encabezados (H1 único, H2s temáticos y H3s para platos/espacios).
  - Bloque estructurado JSON-LD con Schema.org (`LocalBusiness`, `FAQPage`, `BreadcrumbList`).
  - Metadatos completos Open Graph y Twitter Cards.
- **Rendimiento & Accesibilidad**:
  - Cero dependencias externas pesadas; Tailwind CSS optimizado y JS vanilla ultra-ligero (<3 KB).
  - Contraste visual accesible WCAG AAA con sombras de texto de alta definición.
  - Acordeón FAQ accesible e interactivo.
